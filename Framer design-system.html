Patterns · 03

Layout Patterns

Page structure follows a consistent rhythm: label → heading → body → content grid. Sections are separated by 120–160px vertical space.

Page Structure
1. Navbar sticky, frosted glass, 64px
2. Hero pt: 160px, oversized display text + CTA
3. Startups Marquee edge-to-edge scrolling strip
4. Next-Gen Builders Grid auto-fill minmax(220px,1fr)
5. Regional Centers giant city heading links
6. Team Grid auto-fill minmax(200px,1fr)
7. Mentors & Trainers mentor card grid
8. Partners/Sponsors logo strip / scrolling
9. Blogs Grid auto-fill minmax(320px,1fr)
10. CTA Section full-width centered, dark card bg
11. Footer 2-col, pt: 80px

JSON Token Reference

All design tokens are available in design-system.json for use with Tailwind config, CSS-in-JS, or CSS custom properties generation.

// design-system.json — abbreviated view { "colors": { "primitives": { "black": "#0A0A0A", "accent-primary": "#E8FF47", "surface-card": "#1C1C1C" }, "semantic": { "background.default": "#0A0A0A", "text.primary": "#FFFFFF", "interactive.primary-bg":"#FFFFFF", "interactive.primary-hover":"#E8FF47" } }, "typography": { "fontFamilies.display": "'Syne', sans-serif", "fontFamilies.body": "'DM Sans', sans-serif", "textStyles.hero-display": { "fontSize": "clamp(5rem, 14vw, 12rem)", "fontWeight": 800, "lineHeight": 0.92, "letterSpacing":"-0.03em", "textTransform":"uppercase" } }, "spacing": { "base": "4px", "section.lg": "120px", "container.default": "1200px" }, "borders.radius": { "card": "16px", "button": "8px", "badge": "100px" }, "shadows.card": "0 2px 20px rgba(0,0,0,0.4), 0 0 0 1px rgba(255,255,255,0.06)", "motion.transitions.base": "200ms ease" }
Usage
Import design-system.json into your Tailwind config, Style Dictionary, or custom CSS-variables generator to automatically produce all tokens as design primitives ready for immediate use across any new site.
